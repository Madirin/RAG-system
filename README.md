# RAG-system
Реализация RAG системы

Взять датасет 
https://huggingface.co/datasets/bearberry/rus_xquadqa
● Все сегменты объединить в один корпус
○ Внимание на повторы!
● Поднять векторную БД Qdrant (:memory:) и проиндексировать 
корпус.
● Завернуть все в langchain, реализовав функцию поиска по БД.
● На основе функции поиска и LLM реализовать RAG систему.
● Вывести ответы на топ 10 запросов из датасета 2 разными 
моделями, сравнить их по отношению к эталону
